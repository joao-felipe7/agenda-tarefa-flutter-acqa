# agenda-tarefa-flutter-acqa

Projeto Flutter desenvolvido para ACQA de gerenciamento de tarefas diárias.

FUNCIONALIDADES:
- Cadatro e login
- Validação de Campos
- Calendário para seleção de datas
- Adição de tarefas
- Exclusão de tarefas
- Marcação de tarefas como concluídas
- Contagem de tarefas
- Organização de tarefas por data
- Ordenação das tarefas em ordem alfabetica

TECNOLOGIAS:
- Flutter
- Dart
- Statefulwidget
- setState()
- ShowDialog
- TextEditingController
- Chceckbox
- List
- Map
- sort()
- Navigator

Obs.: os dados são armazenados somente na execução do app, sem integração em banco de dados ou firebase

O projeto foi desenvolvido como atividade acadêmica com foco na prática de conceitos de interface, navegação entre telas, gerenciamento de estado e manipulação de listas em Flutter.
